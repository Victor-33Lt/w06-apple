## 어떻게 만들었나요

<!-- 어떤 도구(Copilot Agent 등)를 어떤 순서로 사용했나요? -->

HTML을 사용하여 게임 화면, 점수판, 타이머, 버튼 등의 구조를 만들었습니다.
CSS를 사용하여 어두운 배경, 사과 게임판, 선택 효과, 제거 애니메이션 등 디자인을 구현했습니다.
JavaScript를 사용하여 숫자 생성, 드래그 선택, 합계 10 판정, 점수 계산, 타이머, 최고 점수 저장 기능을 구현했습니다.
게임을 개선하면서 사과가 제거된 후 위쪽 사과가 아래로 떨어지고 빈칸에 새 사과가 생성되는 기능을 추가했습니다.
특수 사과 시스템을 추가하여 게임에 전략적인 요소를 넣었습니다.

## 커스터마이징한 부분

<!-- 기본 예시에서 무엇을 바꾸거나 추가했나요? -->
8×8 게임판: 총 64개의 사과로 구성했습니다.
2분 타이머: 제한 시간 안에 최고 점수에 도전하도록 만들었습니다.
점수 시스템: 제거한 사과 하나당 10점을 획득합니다.
최고 점수 저장: 브라우저의 localStorage를 이용해 최고 점수를 저장합니다.
대각선 연결: 가로와 세로뿐 아니라 대각선으로 인접한 사과도 연결할 수 있도록 변경했습니다.
사과 낙하 및 리필: 사과가 제거되면 위에 있는 사과가 아래로 내려오고, 맨 위의 빈칸에 새 사과가 생성됩니다.
특수 사과 시스템:
💛 황금 사과: 제거하면 추가 50점을 획득합니다.
💣 폭탄 사과: 제거하면 주변 8칸의 사과도 제거됩니다.
🧊 얼음 사과: 제거하면 해당 열의 사과가 모두 제거됩니다.
랜덤 생성: 특수 사과는 각 칸마다 7% 확률로 등장하며, 황금·폭탄·얼음 사과가 같은 확률로 선택됩니다.
반응형 디자인: 다양한 화면 크기에서 게임을 즐길 수 있도록 구성했습니다.
마우스 및 터치 지원: 포인터 이벤트를 사용해 PC와 모바일에서 드래그할 수 있도록 구현했습니다.
